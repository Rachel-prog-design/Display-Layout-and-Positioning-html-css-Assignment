 Project name: Kepler Kigali Campus Website

Project Description
This is a single-page campus information website for Kepler Kigali Campus.  
It provides information about:
- Campus programs
- Student services
- Campus facilities
- Announcements and notices

The website is designed to be easy to navigate, responsive, and visually organized.

Features
- Navigation bar with a **dropdown menu**  
- Introduction section with **description and list of campus info**  
- Campus services section with **service cards**  
- Campus locations/gallery section with **images**  
- Announcements & sticky notice section  
- Display behavior section showing content visibility changes  
- Fully **responsive design** for desktop, tablet, and mobile

Project Files
- `index.html` → Main HTML file  
- `index.css` → External CSS file for styling  
- `README.md` → Project descriptio
